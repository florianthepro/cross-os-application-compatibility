2. Symbols
----------

ASCII mode:
  [OK]   ready or successful
  [!]    attention or update available
  [X]    failed or unavailable
  [-]    not installed
  [..]   operation in progress
  [i]    information

Unicode mode:
  [OK]   ready or successful
  [!]    attention or update available
  [X]    failed or unavailable
  [-]    not installed
  [..]   operation in progress
  [i]    information

Meaning must never depend on color or Unicode.

10. Color rules
---------------

If color is supported:
  green   [OK]
  yellow  [!]
  red     [X] and destructive headings
  cyan    selected item and section heading
  default all normal text

Honor NO_COLOR. Disable color when output is redirected or TERM=dumb.
Never encode state using color alone.

11. Input and accessibility
---------------------------

- Accept upper- and lowercase commands.
- Keep one stable shortcut per action.
- Never start a destructive action on Enter alone.
- Print complete labels for screen readers.
- Avoid animated spinners when reduced motion or non-interactive output is used.
- Preserve a plain-text log without ANSI escape sequences.
- Keep prompts on their own line.
- On Ctrl+C, stop safely before mutation or complete/rollback the atomic step.
- Localize visible text, but keep commands and diagnostic codes stable.
